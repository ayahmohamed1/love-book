# 📖 كتاب الحب التفاعلي • Interactive 3D Love Book

كتاب رومانسي تفاعلي فاخر مصمم بالكامل بنظام **التقليب باللمس/الضغط الحقيقي (Physical 3D Book)** بدون أزرار أو أسهم تشوش المظهر.

---

## 🎨 التنسيق والألوان
- **اللون الأساسي:** برجاندي داكن دافئ وراقي (`#5c0b14`).
- **الورق والكروت:** أبيض كريمي ناعم (`#f6f1e8`).
- **اللمسات الكتابية:** ذهبي/مشمشي كلاسيكي (`#e29b62`).

---

## 📁 مجلدات الصور والأغنية (سهولة التبديل)

تم تنظيم المشروع ليكون التعديل سهلاً من الكود والملفات:
- 🖼️ **مجلد الصور:** `public/images/`
  - `cover.jpg` : صورة الغلاف (شاطئ البحر).
  - `locket-left.jpg` : صورة القلب الأيسر في الميدالية.
  - `locket-right.jpg` : صورة القلب الأيمن في الميدالية.
  - `grid-1.jpg` إلى `grid-9.jpg` : صور شبكة الذكريات الـ 9.
  - `song-cover.jpg` : صورة الطابع البريدي لمشغل الأغنية.
  - `polaroid-1.jpg` و `polaroid-2.jpg` : صور البولارويد لصفحة LOVE.
- 🎵 **مجلد الأغنية:** `public/audio/`
  - `song.mp3` : ملف الأغنية الرومانسية (يمكنك استبداله بأي أغنية).

## 📖 طريقة تصفح الكتاب
1. **فتح الكتاب:** اضغط على أي مكان في الغلاف (`OUR LOVE`) ليفتح الكتاب حركة 3D واقعية.
2. **التقليب للأمام:** اضغط على الصفحة اليمنى.
3. **التقليب للخلف:** اضغط على الصفحة اليسرى.
4. **لوحة المفاتيح:** يمكنك أيضاً استخدام السهمين `⬅️ ➡️` من لوحة المفاتيح.
